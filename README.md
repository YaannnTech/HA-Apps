# Yaannn's Home Assistant Apps

This repository contains Home Assistant apps for local Kokoro text-to-speech and Tuya camera streaming.

It currently includes two apps:
* [Kokoro-FastAPI (CPU)](https://github.com/YaannnTech/HA-Apps/tree/main/kokoro_fastapi)
* [Tuya IPC Bridge](https://github.com/YaannnTech/HA-Apps/tree/main/tuya_ipc_bridge).
* [PhoneBlock Dongle](https://github.com/YaannnTech/HA-Apps/tree/main/phoneblock_dongle)


## Usage

1. Add this repository (`https://github.com/YaannnTech/HA-Apps`) to **Settings > Apps > Install Apps > Repositories**.
2. Refresh the **Install Apps** page.
3. Install the desired app.
